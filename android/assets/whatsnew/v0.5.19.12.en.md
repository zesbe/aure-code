This update finishes the Indonesian translation and removes what was left of the original app's name.

## What's new

- **Command replies follow your language.** `/model`, `/effort` and `/autocompact` now answer in the interface language.
- **Status messages are translated.** Generation errors, Claude Code update progress, git errors and Repair log entries now follow the interface language.
- **Indonesian terminal scripts.** `priv`, `cc-mem`, `pkg` and `aurecode-selftest` print Indonesian messages.
- **Our own release notes.** The "What's new" window and the Changelog page now show Aure Code notes only.

## Other

- The usage share card is marked "Aure Code".
- The hint for installing the toolkit from a local file now points to the `zesbe/aure-code` releases page.
- Untitled sessions show "(Untitled)" in the interface language.
