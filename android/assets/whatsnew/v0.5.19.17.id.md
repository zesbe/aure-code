**Suara ElevenLabs untuk membacakan jawaban.**

- Suara sistem terdengar seperti robot? Isi kunci API ElevenLabs di **Pengaturan → Perangkat & izin → Suara pembaca**. Jawaban, tombol 🔊 Bacakan, dan Mode ngobrol akan memakai suara alami ElevenLabs.
